Статистика за месяц

Инженер Ночных Суточных Отпуск 5-дн. Часов Переработка Отклонение

Общий график хранится в Neon и сохраняется автоматически. Вход — по общему паролю (редактирование) или паролю просмотра (только чтение). Пароль просмотра задаётся кнопкой «Пароль просмотра». Календарь — data/calendar_ГОД.json.

До новых встреч!

График закрыт. Чтобы вернуться, введите пароль.

Сотрудник отдела

5-дневный график заполняется офисом по будням; тип дня — о / у / в — меняется правым кликом по ячейке. «Сформировать график заново» пересобирает строку только этого сотрудника в открытом месяце.

Переработка

Часы прибавляются к итогу месяца и колонке «Переработка». 0 — убрать переработку за этот день.

Вход в график

Введите общий пароль для редактирования или пароль просмотра. Без пароля график остаётся закрытым.

Пароль просмотра

Пароль просмотра открывает график только для чтения: смены, сотрудники и настройки не меняются. Пароль редактирования — общий пароль Neon.

Настройки смен

Часы влияют на статистику и переработку. График будет сформирован заново.
